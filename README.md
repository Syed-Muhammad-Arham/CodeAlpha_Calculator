# CodeAlpha_Calculator 🧮

This repository contains a **Functional Calculator** built using HTML, CSS, and JavaScript. This task was completed as part of the **CodeAlpha** Frontend Development Internship.

## ⚡ Features
- **Basic Operations:** Supports Addition, Subtraction, Multiplication, and Division.
- **Keyboard Support (Bonus):** You can type numbers and operators directly using your keyboard.
- **Error Handling:** Displays "Error" for invalid calculations preventing crashes.
- **Clean UI:** A modern dark-themed interface designed with CSS Grid.
- **Clear & Delete:** Functionality to clear the screen (AC) or delete the last digit (DEL).

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 📂 Project Structure
- `index.html`: Calculator layout.
- `style.css`: Styling for buttons and display.
- `script.js`: Logic for calculations and keyboard events.

## 🖥️ How to Run
1. Clone the repository.
2. Open the `index.html` file in your browser.
3. Start calculating!
